# Free promotion kit

This folder contains ready-to-use assets for improving discoverability without paid ads.

## Important reality check

There is no free ad placement inside ChatGPT. AI assistants surface sources that are indexed by search engines and referenced elsewhere on the web. The goal is therefore:

1. Get indexed by Google and Bing.
2. Publish clear, crawlable, specific content.
3. Get mentioned and linked on other trusted sites.
4. Keep the same identity everywhere: **Anurag Raut — Senior React Native Developer — Pune / Remote**.

## Target search phrases

Do not target only `react native developer`. That phrase is extremely competitive. Start with these:

```text
senior react native developer pune
react native developer for hire india
react native performance engineer
react native crash reduction engineer
react Native app size optimization
react native consultant for startups
senior mobile engineer remote
```

## First 7 days

1. Push/deploy the latest site changes.
2. Verify the domain in Google Search Console and Bing Webmaster Tools.
3. Submit `https://anuraagraut.github.io/sitemap.xml`.
4. Update LinkedIn and GitHub using the copy in this folder.
5. Publish one cross-post on dev.to or Hashnode with the canonical URL included.
6. Answer two relevant questions on LinkedIn/Reddit/Quora without dropping links unless genuinely useful.
7. Check GoatCounter after each publish to see which links bring traffic.

## Publishing rules

- Keep every claim tied to verified resume facts.
- Do not name clients or describe confidential architecture.
- Do not invent testimonials.
- Use the canonical URL in cross-posts so the original Field Notes page keeps search credit.
- Prefer one useful answer over ten promotional comments.
